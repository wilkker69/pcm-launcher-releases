# PcM Launcher: versões

Este repositório só distribui o PcM Launcher.

- **Baixar:** o instalador mais novo fica em [Releases](../../releases/latest).
- **`config.json`:** o launcher lê este arquivo ao abrir. Ele diz qual é a versão mais nova (com o SHA-256 do instalador) e quais anúncios mostrar. Quando a versão muda aqui, o launcher avisa e se atualiza sozinho.

O Windows pode mostrar "O Windows protegeu o computador" na primeira instalação, porque o instalador ainda não tem assinatura digital. Clique em "Mais informações" e depois em "Executar assim mesmo".
